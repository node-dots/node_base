# Пагінація списку груп

Оновлено 18 жовтня 2026 року. [TASK-009](../planning/tasks/10_Jira_Backlog.md#task-009) реалізовано й локально перевірено; командне review ще попереду.

## Запит і відповідь

`GET /api/v1/groups?page=1&pageSize=5`

| Параметр | За замовчуванням | Обмеження |
|---|---:|---|
| page | 1 | Додатне ціле число в безпечному діапазоні JavaScript |
| pageSize | 20 | Додатне ціле число, максимум 100 |

Параметри передаються десятковими рядками без знака, пробілів і початкових нулів. Порожні, дробові, від’ємні, повторені та невідомі параметри повертають HTTP 400 з кодом VALIDATION_ERROR. Перевірені значення перетворюються на числа.

Відповідь HTTP 200 містить data — масив DTO груп — та meta:

```json
{
  "page": 1,
  "pageSize": 5,
  "total": 8,
  "totalPages": 2
}
```

total — кількість усіх груп; totalPages = Math.ceil(total / pageSize). Для 8 груп сторінки розміром 5 містять 5, 3 та 0 записів. За межами списку data порожній, номер запитаної сторінки зберігається. У порожній базі total=0 і totalPages=0. Порядок — за MongoDB _id за зростанням; у DTO це поле id.

## Шлях даних

1. group.schema.js описує формат query; validateQuery перевіряє його та записує числа у request.validatedQuery.
2. GroupController передає параметри в GroupService, а отримані групи перетворює на DTO.
3. GroupService викликає repository та обчислює totalPages.
4. GroupRepository виконує find/sort/skip/limit і countDocuments у MongoDB. У пам’ять застосунку завантажується лише обрана сторінка.

Swagger використовує ту саму query-схему; метадані .openapi() уточнюють числовий контракт після перетворення рядків. Операція та помилка 400 описані в group.openapi.js. [Як підтримувати Swagger](../development/11_OpenAPI_Generation.md).

Aggregation GET /api/v1/groups/summary охоплює всі групи й не залежить від сторінки списку. Авторизація ще не реалізована; після її додавання find і count повинні застосовувати однаковий scope.

find і count — два окремі читання без спільного знімка. За одночасних змін даних total і сторінка можуть тимчасово розходитися; між запитами offset-пагінація також може зміщувати записи. Стабільний порядок гарантується для незмінних даних.
