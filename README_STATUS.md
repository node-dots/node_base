# Стан реалізації навчального проєкту

**Проєкт:** backend системи управління дитячим садком.  
**Дата звіту:** 18 жовтня 2026 року. **Версія:** 0.3.0.

Команда підготувала базу для подальшої розробки та реалізувала перший наскрізний сценарій: HTTP-запит → перевірка даних → бізнес-логіка → збереження в MongoDB → відповідь API.

## Що реалізовано

- **Кодова база:** Node.js, Express, JavaScript ESM. Обрано модульний моноліт зі структурою `routes → controller → service → repository → model`. Контролери, сервіси та репозиторії реалізовано класами; залежності передаються через конструктори (DI). DTO визначають формат відповіді, константи зберігають спільні коди та обмеження.
- **База даних:** підключення MongoDB через Mongoose, запуск локальної бази через Docker Compose, збереження даних у Docker volume. Підготовлено seed для восьми демонстраційних груп; повторний запуск зберігає наявні записи та ручні зміни.
- **Модуль груп:** створення групи зі статусом `DRAFT`, отримання списку з пагінацією та окремої групи. Параметри page/pageSize перевіряються; відповідь містить загальну кількість записів і сторінок. Пагінацію перевірено HTTP-тестами та інтеграційним тестом із MongoDB. Реалізовано MongoDB Aggregation Framework для підрахунку кількості груп і загальної місткості за віковими категоріями.
- **Базовий HTTP-захист:** валідація Zod, захисні заголовки Helmet, загальний та окремий для запису rate limit, обмеження розміру JSON, HTTP-тайм-аути й централізована обробка помилок.
- **Інструменти розробки:** Swagger UI та генерація OpenAPI зі схем Zod і описів операцій; локальний tracing OpenTelemetry у Jaeger; запуск із debugger. Додано перевірки стану процесу та доступності MongoDB.
- **Перевірки якості:** автоматизовані тести API, валідації, HTTP-захисту, телеметрії та готовності застосунку; окрема інтеграційна перевірка з MongoDB. Підготовлено команди перевірки синтаксису та форматування Prettier.
